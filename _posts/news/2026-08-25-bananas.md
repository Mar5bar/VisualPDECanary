As with many modern web-based projects, VisualPDE has evolved continuously since we publicly launched it three years ago. We have recently implemented a fairly substantial update to the core simulation interface. We thought it would be a good idea to start a news page to explain and motivate these changes, as well as discuss other things over time as we continue to develop things in response to user feedback.

# {{ layout.equations }} User Interface Changes
The most significant change from a user perspective is that the {{ layout.equations }} button will now open an entirely redesigned user interface for modifying equations, parameters, etc. Below is a "before and after" image of the old interface and the new one.

<img class="center" style="width:70%;aspect-ratio:1;background-image:url('/assets/images/OldNewEquationsMenu.jpg');background-size:cover;" src="/assets/images/OldNewEquationsMenu.jpg" alt="Old and new equations menus">
<small>(Left) Old equations user interface (right) new equations user interface.</small>

Much of the redesign focused on rearranging existing interfaces, such as the ability to change the number and name of the independent variables to be more prominent (in the ``Variables`` submenu), or more clearly highlighting what each of the ``Equations`` submenus was modifying in the typeset equation above. The ``diffusion coefficients`` submenu also has a grid button that opens up a matrix within which you can enter (cross)-diffusion coefficients directly, including arbitrary nonlinear expressions of the independent and dependent variables. ~~We have~~ Adam has also spent time polishing the fonts and size/colour of this new UI, leading to an overall more polished look to the interface throughout.

In addition to rearranging existing functionality, we have also added a ``Substitutions`` menu that allows you to make new variables that can be arbitrary functions of any independent or dependent variable. These can then be placed in equations, initial or boundary conditions, or as expressions to plot. They can also be used to break up messy or complicated expressions into smaller chunks, making it easier for you to check your design. Finally, each individual variable defined in the ``Substitutions`` menu can be typeset or not, as you would like, in order to present the important parts of the model to the user. For example, you may want to hide a messy initial condition that is easier to break into several substitution variables to focus the typesetting on things only of relevance to the equation.

# Eight is bigger than four
When we first built VisualPDE, we used a single RGBA texture to store the data of any given simulation. This meant that we had the ability to represent four dependent variables at any given time. Recently, we played around with adding a second texture, and realized that this had almost no impact on performance across a range of devices. So now you are allowed to build equations involving between one and eight dependent variables, each of which can be an ``algebraic`` variable that has no time derivatives, or a time-evolving quantity. See the page on [what VisualPDE can solve](user-guide/what-can-visualpde-solve) for further details
